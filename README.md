
# BookHub 📚

## 📌 Trilha do Projeto

Desenvolvimento de uma aplicação web básica para organização de um acervo de livros, com foco na prática de programação, manipulação de dados e criação de funcionalidades essenciais.

**Etapas da trilha:**
1. Planejamento da aplicação e definição dos requisitos.
2. Desenvolvimento da interface do usuário.
3. Implementação do cadastro e gerenciamento de livros.
4. Criação de funcionalidades de busca e filtragem.
5. Testes e documentação do projeto.

## 📚 Acervo Escolhido

**Livros**

O sistema permitirá organizar um acervo de livros com informações como título, autor, gênero, ano de publicação e descrição.

## 📝 Descrição do Projeto

O BookHub é uma aplicação desenvolvida para facilitar a organização e a consulta de um acervo de livros.  
A plataforma permite visualizar, cadastrar, editar e excluir livros.  
Também possibilita pesquisar títulos e organizar as obras por categorias.  
O projeto tem como objetivo praticar conceitos fundamentais de desenvolvimento de software e gerenciamento de dados.

## 🎯 MVP (Produto Mínimo Viável)

Desenvolver uma aplicação funcional que permita cadastrar, listar, consultar, editar e excluir livros de um acervo, com informações básicas para identificação e organização das obras.
