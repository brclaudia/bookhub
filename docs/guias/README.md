# Guias

Passo a passo para quem for usar, rodar ou evoluir o BookHub. Cada guia deve caber em um arquivo próprio quando passar de um rascunho.

## Previstos

| Guia | Objetivo | Estado |
| --- | --- | --- |
| Ambiente local | Como instalar dependências e subir a aplicação | a escrever |
| Cadastro de um livro | Como incluir uma obra e conferir se ela aparece na listagem | a escrever |
| Busca e filtros | Como pesquisar por título e organizar por gênero | a escrever |
| Contribuição | Como propor mudança, atualizar a documentação e registrar um ADR | a escrever |

## Modelo de guia

```md
# Título do guia

## Quando usar

## Pré-requisitos

## Passos

1. ...

## Como saber que deu certo

## Problemas comuns
```
