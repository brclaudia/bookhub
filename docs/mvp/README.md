# MVP

Produto mínimo viável do BookHub: uma aplicação funcional para cadastrar, listar, consultar, editar e excluir livros, com os dados básicos de identificação e organização.

## Objetivo

Praticar planejamento, interface, manipulação de dados, busca e documentação em um acervo real de livros.

## Entra no MVP

- Visualizar o acervo.
- Cadastrar um livro com título, autor, gênero, ano de publicação e descrição.
- Consultar um livro.
- Editar um livro existente.
- Excluir um livro.
- Pesquisar por título.
- Organizar ou filtrar obras por categoria.

## Critério de pronto

O MVP está pronto quando uma pessoa consegue manter o acervo (incluir, alterar, consultar e remover) e encontrar um livro por título ou gênero, com o comportamento coberto em [testes](../testes/README.md).

## Trilha

1. Planejamento da aplicação e definição dos requisitos.
2. Desenvolvimento da interface.
3. Cadastro e gerenciamento de livros.
4. Busca e filtragem.
5. Testes e documentação.
