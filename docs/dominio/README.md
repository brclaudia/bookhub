# Domínio

Linguagem do acervo de livros: o que cada conceito significa e quais regras o BookHub precisa respeitar.

## Conceitos

| Conceito | Significado |
| --- | --- |
| Livro | Obra do acervo, identificada por título, autor, gênero, ano de publicação e descrição |
| Acervo | Conjunto de livros organizados na aplicação |
| Gênero | Categoria usada para agrupar e filtrar obras |
| Busca | Consulta por título (e, no futuro, por outros campos) |

## Regras conhecidas

- Cada livro precisa das informações básicas para ser identificado e organizado.
- O acervo permite incluir, alterar, consultar e remover livros.
- A consulta precisa encontrar títulos e separar obras por categoria.

## Fora do domínio por enquanto

_Itens que ainda não fazem parte do problema, como empréstimo, usuários ou avaliações. Registrar aqui quando forem explicitamente deixados de fora._

| Termo | Definição |
| --- | --- |

| Categoria | Sinônimo de gênero na descrição do produto |
